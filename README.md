 Vitala — Functional Medicine Landing Page

A responsive landing page for **Vitala**, a functional medicine platform designed for employers.

This project was built as a collaborative group project using **React, Vite, and Tailwind CSS**.

 🔗 Live Website

Live Demo: https://vitala-group-project.vercel.app/

 Features

* Responsive navigation and hero section
* About Vitala section
* Responsive image triptych
* Interactive dashboard/accordion
* Statistics section
* Three-tier pricing section
* Call-to-action footer
* Responsive design for desktop, tablet, and mobile

 Getting Started

 1. Clone the repository

```bash
git clone https://github.com/Ebereonwu-prince-chimdi/vitala-group-project.git
```

 2. Enter the project directory

```bash
cd vitala-group-project
```

 3. Install dependencies

```bash
npm install
```

 4. Start the development server

```bash
npm run dev
```

The project will then be available at the local development address shown in your terminal.

 5. Build for production

```bash
npm run build
```

 🔀 Git Workflow

We used a collaborative Git workflow where each team member worked on their own feature branch.

```text
main
  ↓
feature branch
  ↓
development
  ↓
commit
  ↓
push
  ↓
Pull Request
  ↓
code review
  ↓
Tech Lead merge
  ↓
main
```

No team member pushed directly to `main`. Pull Requests were reviewed before being merged by the Tech Lead.

 📱 Responsive Design

The landing page was developed to work across desktop, tablet, and mobile screen sizes, with particular attention to the 320px mobile breakpoint.
